CalBar is a macOS menu bar app that shows calendar event progress and today's reminders.

## Common Issues

### Calendar or Reminders do not appear

Please open macOS System Settings and make sure CalBar has permission to access Calendar and Reminders.

### The progress bar does not show

CalBar only shows the compact progress bar when there is a current calendar event or an upcoming event today.
